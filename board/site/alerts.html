Alerts

Get a notification on this phone when new picks and parlays post. Alerts are sent by the scheduled runs, so they cost no extra Odds API credits.

1. Pick sports

2. Turn on alerts

3. One-time setup: save this phone's alert code

  1. On GitHub, open your nfl-betting-model repository, then Settings, Secrets and variables, Actions.
  2. Tap New repository secret, name it GG_PUSH, paste the code as its value, and save. For a second phone, update the secret with both codes, separated by a space.
  3. Done. The next time a scheduled run posts a new board, this phone gets an alert.

This code lets the runs send alerts to this phone only. Treat it like a password: keep it in that GitHub secret, not in chats, emails or the repository. If you turn alerts on again, a new code replaces this one.

On iPhone, alerts only work from the installed app: open this site in Safari, tap Share, then Add to Home Screen, and open this page from the GoonerGamble icon.
